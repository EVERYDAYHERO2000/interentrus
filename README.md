<h1 align="center">InterenetBalans</h1>
<p align="center">Личные кабинеты провайдеров Московской области в Home Assistant<br>Нетнорд · Микронмедиа</p>

Интеграция для абонентов интернет-провайдеров **Нетнорд** и **Микронмедиа**
в Московской области. Позволяет видеть баланс и абонентскую плату в Home Assistant,
а также получать напоминания, когда пора пополнить счёт.

Данные берутся из личного кабинета по логину и паролю. Настройка — через
интерфейс Home Assistant, без YAML.

## Поддерживаемые провайдеры

| Провайдер | Личный кабинет | Поддержка |
| --- | --- | --- |
| **Нетнорд / Net-Nord** | [cabinet.net-nord.ru](https://cabinet.net-nord.ru/cabinet/welcome/) | Реализовано |
| **Микронмедиа / Micronmedia** | [app.micmedia.ru](https://app.micmedia.ru/auth) | Реализовано |

При добавлении выберите своего провайдера: **Нетнорд** или **Микронмедиа**.
Проект независимый и не является официальной интеграцией провайдеров.

## Сенсоры

| Сенсор | Источник |
| --- | --- |
| Баланс | Остаток средств из личного кабинета, ₽ |
| Абонентская плата | Месячная стоимость тарифа из личного кабинета, ₽ |
| Стоимость дня | Рассчитывается интеграцией: абонплата / число дней текущего месяца, ₽ |
| Пора пополнить | Рассчитывается интеграцией по балансу и абонплате |

Из кабинета запрашиваются только баланс и абонплата. Для Нетнорда используется
страница лицевого счёта, для Микронмедиа — два запроса API: баланс и тариф.
Абонплата отражает стоимость тарифа без дополнительных услуг.

Вычисления выполняются внутри интеграции, без шаблонов YAML и дополнительных
запросов. Стоимость дня отображается с точностью до копейки. Она пересчитывается
также в полночь по часовому поясу HA, с учётом числа дней в текущем месяце.
Если абонплата неизвестна, вычисляемые значения также будут неизвестны;
при отрицательном балансе напоминание включается независимо от абонплаты.

## Установка через HACS

Требуется **Home Assistant 2026.3.0 или новее**.

[![Открыть в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=EVERYDAYHERO2000&repository=interentrus&category=integration)

1. В HACS откройте **⋮ → Пользовательские репозитории / Custom repositories**.
2. Добавьте `https://github.com/EVERYDAYHERO2000/interentrus`, тип **Integration**.
3. Найдите и скачайте **InterenetBalans**.
4. Перезапустите Home Assistant.
5. Откройте **Настройки → Устройства и службы → Добавить интеграцию → InterenetBalans**.
6. Выберите провайдера и введите логин и пароль личного кабинета.

Для ручной установки скопируйте папку `custom_components/isp_balance` в
`/config/custom_components/isp_balance`, перезапустите HA и добавьте интеграцию
через интерфейс.

## Настройки

Откройте **Настройки → Устройства и службы → InterenetBalans → Настроить**.

| Параметр | По умолчанию | Допустимые значения |
| --- | --- | --- |
| Интервал обновления | 60 минут | От 5 до 1440 минут |
| Напоминать за сколько дней | 3 дня | От 0 до 365 дней |

Интервал задаёт общий опрос аккаунта для всех сенсоров. Сохранение настроек
перезагружает интеграцию и сразу обновляет данные. Можно также вызвать действие
`homeassistant.update_entity` для любой сущности аккаунта.

«Пора пополнить» включается, когда:

```text
баланс ≤ абонплата / число дней текущего месяца × порог в днях
```

Например, при абонплате 930 ₽ в месяце из 31 дня стоимость дня — 30 ₽.
С порогом 3 дня напоминание включится при балансе 90 ₽ или меньше.
В сравнении используется точная стоимость дня до округления. При отрицательном
балансе напоминание включено; при бесплатном тарифе и неотрицательном балансе
пополнение не требуется.

Для уведомлений создайте автоматизацию с переходом сенсора «Пора пополнить»
в состояние `on` и действием отправки уведомления. Интеграция не выполняет
платежи и не изменяет подключённые услуги.

При обновлении до 0.5.0 удалённые сенсоры предыдущих версий автоматически
убираются из реестра сущностей. Баланс, абонплата, стоимость дня и напоминание
сохраняют свои идентификаторы.

## Учётные данные

Логин и пароль хранятся в конфигурации Home Assistant. При смене пароля
интеграция предложит повторную авторизацию. Не публикуйте учётные данные
и содержимое личного кабинета в сообщениях об ошибках.
