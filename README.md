Пользовательская интеграция получает баланс и сведения о тарифе из личного
кабинета по логину и паролю. Показывает, на сколько дней хватит денег, и помогает
напомнить о пополнении. Настраивается через интерфейс Home Assistant, без YAML.

**Поддерживается Нетнорд. Микрон пока в планах и в интерфейсе не предлагается.**
Проект независимый, не является официальной интеграцией провайдеров.

> Первая версия для проверки на реальной установке. Структура кабинета изучена
> после ручного входа, тесты клиента и расчётов проходят. Сквозная проверка входа
> Python-клиентом и запуск в установленном Home Assistant ещё не выполнены.

## Возможности

| Сущность | Что показывает |
| --- | --- |
| Баланс | Остаток средств, ₽ |
| Хватит до | Дата из прогноза провайдера |
| Минимальный платёж | Требуемая сумма из кабинета, ₽ |
| Абонентская плата | Месячная стоимость текущего тарифа, ₽ |
| Расходы за текущий месяц | Сумма расходов по всем отображаемым услугам, ₽ |
| Текущий тариф | Название тарифа |
| Стоимость дня | Расчёт: абонплата / число дней месяца, до копеек |
| Осталось дней | Разница между прогнозной датой и сегодня, минимум 0 |
| Пора пополнить | Бинарный сенсор напоминания |

Опрос — раз в час. Число оставшихся дней и напоминание пересчитываются также
в полночь по часовому поясу Home Assistant. Для досрочного обновления вызовите
действие `homeassistant.update_entity` для любой сущности интеграции.

## Установка через HACS

Нужны **Home Assistant 2026.3.0 или новее**, установленный HACS и доступ к
`https://cabinet.net-nord.ru` с сервера HA.

[![Открыть репозиторий в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=EVERYDAYHERO2000&repository=interentrus&category=integration)

Либо добавьте вручную:

1. В HACS откройте меню **⋮ → Пользовательские репозитории / Custom repositories**.
2. Укажите `https://github.com/EVERYDAYHERO2000/interentrus`, тип **Integration**.
3. Найдите **ISP Balance** и скачайте интеграцию.
4. Перезапустите Home Assistant.
5. Откройте **Настройки → Устройства и службы → Добавить интеграцию → ISP Balance**.
6. Выберите Нетнорд и введите логин и пароль кабинета.

Репозиторий подготовлен для добавления как пользовательский в HACS. Это не
означает включение в основной каталог HACS.

## Ручная установка

Скопируйте `custom_components/isp_balance` в
`/config/custom_components/isp_balance`, перезапустите HA и добавьте интеграцию
через интерфейс, как описано выше.

## Настройка напоминания

В разделе **Настройки → Устройства и службы → ISP Balance → Настроить**
укажите порог в днях: по умолчанию **3**, допустимо от **0 до 365**.

«Пора пополнить» включается при любом из условий:

- осталось не больше заданного числа дней;
- баланс равен нулю или отрицательный;
- минимальный платёж в кабинете больше нуля.

Интеграция предоставляет сенсор. Для push-уведомления создайте автоматизацию HA
с переходом «Пора пополнить» в состояние `on` и действием отправки уведомления.
Интеграция не выполняет платежи и не изменяет услуги.

## Обновление и удаление

Обновляйте через HACS и перезапускайте Home Assistant. При переходе с ручной
установки добавьте репозиторий в HACS и скачайте его поверх существующей папки.
Идентификаторы сенсоров «Баланс» и «Хватит до» сохранены с версии 0.1.0.

Для удаления сначала удалите запись интеграции из «Устройства и службы»,
затем удалите интеграцию через HACS и перезапустите HA.

## Ошибки и ограничения

- **Ошибка входа:** проверьте данные на сайте провайдера. При смене пароля HA
  предложит повторную авторизацию.
- **Сущности недоступны:** проверьте доступность кабинета с сервера HA.
- **Неизвестное значение:** кабинет не отдал поле или его формат изменился.
  Отсутствующие данные не подменяются нулём. Без прогноза даты напоминание может
  оставаться неизвестным, если баланс и минимальный платёж не требуют пополнения.
- **Смена месяца:** старые расходы и расчёт стоимости дня не переносятся в новый
  месяц до успешного обновления.
- **Стоимость дня:** расчёт по тарифу, без индивидуальных скидок и разовых услуг.
  Прогноз «Хватит до» берётся непосредственно у провайдера.
- **Состояние интернета:** интеграция читает биллинг, доступность соединения не измеряет.
- **Иконка:** поставляется локально в `brand/`, поддерживается начиная с HA 2026.3.

Если проблема повторяется, [создайте issue](https://github.com/EVERYDAYHERO2000/interentrus/issues/new/choose)
с версиями HA и интеграции и обезличенными логами.

## Учётные данные

Логин и пароль хранятся в конфигурационной записи Home Assistant; cookies —
в памяти отдельной сессии аккаунта. Проверка TLS включена, отправка данных
на другой домен запрещена. Пароли и содержимое страниц не записываются
интеграцией в логи. Защищайте конфигурацию HA и её резервные копии.
Не прикладывайте пароли, cookies, токены и полные страницы кабинета к issues.

## Разработка

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/ruff check custom_components tests scripts
.venv/bin/ruff format --check custom_components tests scripts
```

36 тестов проверяют парсинг, авторизацию на тестовых ответах, восстановление
сессии, ограничение адресатов, расходы, календарные расчёты и пороги напоминания.
Тестовые данные синтетические. GitHub Actions дополнительно запускает HACS
validation и hassfest; их фактический результат смотрите во вкладке Actions.

Иконка — оригинальная геометрическая графика проекта; исходный генератор:
`scripts/generate_icon.py` (Pillow). Экспорт: PNG 256×256 и 512×512.

## English

Custom Home Assistant integration for ISP billing balances, tariff information
and top-up reminders. Currently supports **Netnord**; Micron is planned.
Requires Home Assistant 2026.3+. Add this repository to HACS as an **Integration**,
download, restart HA and add **ISP Balance** in Devices & services. Credentials
are configured in the UI. Live Python login and full HA runtime validation are
still pending. This is an independent community project.
